# How to use GRPO Colab Notebook to Reproduce the Results

1. **Install the correct *Unsloth* version**: Run the cell where unsloth==2025.5.7 is installed.
2. **Select the model**: In the next cells, you can select the model you want to train. Then you adjust the hyperparameters if needed and start the training.
3. **Run the strawberry test**: At the end of the colab notebook, run the function *strawberry_test*. It outputs the models response in the required format with its counting of the letter r and its reasoning approach.
